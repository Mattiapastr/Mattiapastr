# BRILIA 2.2 profile visuals

Design sources: BRILIA 2.2 Design System DNA v0.4 (22 October 2026) and the granular ink illustration specification v0.3 (28 October 2026).

Archivo 900/400 and Space Mono 400, converted to SVG outlines. Fonts from Google Fonts, under their respective Open Font Licenses. Paper #EAE8E3, ink #0F0F0F, amber #D88A4D, sage #65A88D, dark band #163829. Square corners, hard borders and no gradients.

Each SVG has light/dark and desktop/mobile variants, a title and descriptive labels. The README repeats key facts as real text. The ink illustration is a separate image, so measured data is rendered precisely in SVG.

Content sources: the approved profile text; k3-plugin-cc public repository; CodeBurn rolling 30-day view captured on Charlie Windows PC on 29 October 2026; internal BRILIA Organigramma v5.0 dated 5 September 2026.

Illustration brief: three panoramic granular ink vignettes on warm paper, showing a desktop PC with connected workflows, hands reviewing documents with a magnifier, and two computers exchanging a reviewed document. Strong irregular contours, hatching, stippling, localized ink grain, charcoal with restrained sage and amber. No lettering, logos, gradients or 3D.
